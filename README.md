# FitLife Health Tracker

##  Project Overview

**FitLife Health Tracker** is a web-based health and fitness management platform designed to help users monitor and manage their daily health and fitness activities.

The main goal of this project is to provide users with a simple platform where they can track important health-related information and maintain a healthy lifestyle.

##  Objectives

- Help users monitor their daily health and fitness activities.
- Provide a centralized platform for health tracking.
- Make health-related information easy to manage.
- Provide a simple and user-friendly interface.
- Store and manage user data securely using a database.

##  Features

- User-friendly health tracking interface
- User registration and login
- User profile management
- Health and fitness data tracking
- Daily activity tracking
- Health-related information management
- PHP-based dynamic web pages
- MySQL database integration
- Form submission and data management
- Responsive web design

##  Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Client-side functionality
- **PHP** – Server-side development
- **MySQL** – Database management
- **phpMyAdmin** – Database administration
- **Apache** – Web server

## ⚙️ Requirements

To run this project locally, you need:

## 🚀 How to Run Locally

### 1. Clone the Repository
git clone https://github.com/romioraz1107-spec/FitLife_Health_Tracker.git

### 2. Move the Project

If you are using XAMPP, place the project inside:
C:\xampp\htdocs\
For example:
C:\xampp\htdocs\FitLife_Health_Tracker\
### 3. Start XAMPP

Start:
Apache
MySQL
### 4. Create the Database

Open:
http://localhost/phpmyadmin
Create the required database and import the project's .sql file if one is provided.

### 5. Configure Database Connection

Update the database configuration file with your local MySQL details:

$host = "localhost";
$username = "root";
$password = "";
$database = "your_database_name";

### 6. Open the Website

Open:
http://localhost/FitLife_Health_Tracker/
